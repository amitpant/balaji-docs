# Admin guide (for Balaji Construction)

_To be completed in Phase 3 with screenshots._

## Add a project

1. Open `yourdomain.com/admin` and log in.
2. Go to **Projects → Add project**.
3. Fill in the title, category, status and cover photo. Everything else is optional — leave it empty and it won't show.
4. Upload more photos and drag them into order.
5. Paste YouTube links for any videos.
6. Switch **Publish** on when it's ready. Until then, only admins can see it.

## Answer enquiries

New enquiries arrive by email and in **Enquiries**. Mark each one **Contacted** or **Closed** as you go.
